An operations assistant that watches your systems and answers on Telegram.

Homelab Assistant is a Claude-powered tool I built to run my own servers and small IT-support tasks. It checks that sites, certificates, backups and machines are healthy, sends a short daily briefing, and takes plain-English requests from a chat window.

Get in touch

What it does

Watches infrastructure

Regular checks on websites, SSL certificates, domain expiry, disk and memory, containers and backups. A problem becomes a message, not a surprise.

Daily briefing

Each morning it sends one summary: overnight alerts, system health and anything that needs a decision.

Answers questions

Ask "what is the status?" or "why did that alert fire?" in plain English over Telegram and get an answer based on live data.

Handles routine IT tasks

Helps triage helpdesk tickets, drafts replies for review, and prepares routine changes. A person approves anything that changes a system.

How Claude is used

  • Reasoning over alerts. Claude reads the raw output of the checks and explains what is wrong and what to do next.
  • Conversation. Claude is the layer that turns a short chat message into the right checks and tools.
  • Drafting and review. Claude writes summaries and ticket replies, and reviews changes and code before they are used.
  • Built with Claude Code. Much of the assistant's own tooling is written, tested and reviewed with Claude Code.

How it works

Telegram message→ Claude→ Checks and tools→ Answer or alert

Scheduled checks run on small always-on machines. Results flow back through the same chat, so there is one place to look. Secrets stay on the servers, and actions that change something need explicit approval.
